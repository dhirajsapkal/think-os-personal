### Highlights

- **The Pair — one device for the whole story** — every homepage beat is now a two-pane vignette: LEFT what you typed in Claude Code, RIGHT the plain markdown file that was read or written because you typed it. The product is shown, not paraphrased. Stacks vertically on mobile; the hairline connector rotates with it
- **A day with it → four cause/effect moments** — 08:40 a morning brief (file READ), 14:00 an automatic work-log entry you typed nothing to trigger (+3 lines), 16:30 a decision captured in one line (+1 entry), Sunday 20:00 the staleness flag and `/weekly-review` (Current Focus replaced). Every left-pane line mirrors a shipped playbook
- **The visual system is the message** — new functional design tokens make diff-green mean "a line the product wrote" and accent mean "a file it read," everywhere on the site. Documented AA contrast on both (4.9:1 light, 8.7:1 dark)
- **How it works, in three nodes** — your files → a local index → every session, joined by arrows; the architecture in one glance instead of three paragraphs
- **Quieter chrome, sharper devices** — retired the serif pullquote, section numerals, and decorative ornaments in favor of markdown-source headings (`## ` in accent) and a mono blockquote, so the site is built from the same stuff the product manages
- **Commands page gains a zero-dependency filter** — type to narrow all 36 commands; empty groups hide themselves
- **Guide gains a static anchor TOC** — jump to the mental model, your first week, the daily and weekly rhythms, dos and don'ts, or the cheat-sheet; no JavaScript required
- **Website-only release** — no scripts, templates, instructions, or playbooks changed

### What changed

The v0.9.4 homepage answered "now what?" but still opened on long-form prose — a Design Lead's note that even a trimmed essay reads as an essay. This release commits to one bold idea instead: Think OS is two surfaces — a terminal where you talk and a folder of plain files that change because you talked — so the site shows exactly that pairing and lets the copy fall back to captions.

The signature `Pair` component (new, with `TerminalPane`, `FilePane`, and `DiffPane`) renders that cause/effect everywhere: the hero demonstrates the morning brief reading two small files; "A day with it" walks four moments from a single command to an automatic capture to a one-line decision to the Sunday review; even the 404 page is a `cat 404.md: No such file or directory`. The retired `ConversationStrip` is gone; `FlowDiagram` carries the three-node architecture.

Crucially, the design tokens themselves became functional. Rather than decorative color, diff-green (`--add`) is reserved for lines the product *wrote* and the brand accent for files it *read* — so a glance at any artifact on the site tells you what happened, with the contrast ratios verified for AA in both themes. All motion stays behind `prefers-reduced-motion` guards (the hero typing, scroll reveals, and staggered diffs all collapse to static, fully-visible states), focus-visible and the skip link are intact, and dark mode is fully styled.

Every behavioral claim in the rebuilt homepage still traces to a shipped playbook: the decision entry's `**Decision** / **Why** / **Context** / **Applies to**` fields match `thinkos-capture.md` decision mode, the capture beat's "file paths, file counts, a commit hash — never content" matches `thinkos-autosave.md`, and the staleness line matches the `SessionStart` hook from v0.9.3. The version stamp, changelog collection, RSS feed, 404, both `netlify.toml` files, and the standalone-deploy build are unchanged and green.

### Upgrade

Nothing to do — this is a website-only release. `/thinkos-update --pull` does not touch the site; pull the repo to see the rebuilt pages. Standalone Netlify deploys of `website/` build unchanged via `npm run build` (the `prebuild` step still snapshots `VERSION`).
