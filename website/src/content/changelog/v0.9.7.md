### Highlights

- **A step engine drives every scene** — beats fire in order on scroll entry: command types → annotation → connector draws → files light up as read → the answer prints. Nothing renders before its trigger.
- **Type something, for real** — the demo terminal takes free input now. Four matched demos including `log …`, which writes your own words into a `Work Log.md` diff with a file side-effect chip; everything else gets an honest "(demo) that one needs the real install."
- **Beat badges** — `[1] you say it · [2] it reads · [3] it answers` narrate The Read, so the two-pane diagram explains itself.
- **A third less copy** — captions instead of paragraphs; a file-chip grid replaces a sentence about files.

### What changed

The previous release got the world right and the storytelling wrong: typed commands played while their answers were already on screen, and the diagrams assumed you knew what you were looking at. This pass makes the animation the explanation — cause, then effect, in reading order — and turns the strongest moment (typing) into something you do, not just watch. Reduced-motion and no-JS still render every scene static and complete.

### Upgrade

Nothing to upgrade — website-only. Redeploy to pick it up.
