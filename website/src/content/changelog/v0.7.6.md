### Highlights

- `40-emergent-seeding.md`, `50-drift-detection.md`, and `60-shared-mode.md` are now in the wired instruction list — six-line fix to two scripts
- **Shared-mode redaction actually enforces now** — previously `/thinkos-shared on` toggled a flag file that nothing read
- `templates/instructions/README.md` rewritten to list all eight curated blocks in actual wired order

### What happened

The setup and update scripts build the agent's always-loaded instruction block by concatenating a list of curated files. Three files were never on that list. The rendered block even had a "Where to look next" pointer claiming all three sections were concatenated below — in reality the script jumped straight from write-targets to the adapter block, omitting 156 lines of ambient-behavior instructions.

Consequences: emergent seeding silently no-op'd for every new install (the agent never saw stub markers on HOT files), mid-flow drift never got flagged, and — most consequentially — a user toggling shared-mode before a screen-share would have reasonably trusted that `tier: sensitive` notes were hidden. They weren't.

### What changed

All three blocks are in the wired list, in declared order. The instruction block grows from ~390 to ~530 lines per session — a real token cost, but the alternative (deleting claimed product behavior) was the bigger lie. The shape to avoid, recorded for posterity: feature documented, code shipped, wiring forgotten.

**Upgrade:** `/thinkos-update` from any session picks up the wired blocks.
