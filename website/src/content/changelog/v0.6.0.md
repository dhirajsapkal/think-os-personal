### Highlights

- `/thinkos-vitals` — one-command vault health snapshot
- `/thinkos-sync` — cross-machine sync that pauses to you on conflict
- Opt-in launchd job for scheduled vault sync (default: weekday 6pm)

### What changed

**`/thinkos-vitals` makes vault decay visible.** Before this release, the OS could rot silently — stale `Current Focus`, a growing autocapture backlog, broken cross-links, all invisible until you ran a narrow check like `/thinkos-stale` or the Sunday `/weekly-review`. Now one command shows you per-file freshness, line-count budgets, unreviewed captures (7d / 30d), broken wikilinks, and section ages for the append-only logs. JSON output mode for tooling, human output for terminals. After the report, four chip-picker actions: address the oldest stale file, batch-review autocaptures, fix broken links, or close.

**`/thinkos-sync` makes multi-machine setups first-class.** The previous answer was "pick a sync strategy and good luck" — punted in `LIMITATIONS.md`. Now there's one command that auto-commits unstaged changes, fetches, rebases, and pushes. **Merge conflicts pause to you. Never auto-resolved.** Two-machine round-trip on the personal hub takes one command — or zero, if you install the optional launchd job that fires at 6pm on weekdays.
