### Highlights

- **This page exists now** — a public `/changelog` rendered from an Astro content collection, with an RSS feed at `/rss.xml`
- **Documentation sweep across 12 files** so the README, AGENTS.md, INSTALL.md, and the playbooks reflect the current v0.7.0 state
- **Website refresh** — five new components, corrected version stamps, regrouped command list, honest FAQ

### What changed

The maintainer-facing `CHANGELOG.md` stays the inventory; this page is the friendlier read. It launched with five entries — v0.4.4 through v0.7.0 — newest-first, each with highlights, short prose for the headline features, and an upgrade footer.

The website got a real refresh alongside it: a three-panel conversation strip showing actual Claude Code transcripts (real `mcp__basic-memory__*` tool names, no fabrication), a CSS-only vault tree, a trust bar, a "Plays well with" row, and the "See what's new" line under the install prompt. Version stamps in the header and footer were corrected (they were still saying v0.4). The slash-command list was regrouped from a flat 24-entry list into six workflow groups, and the FAQ no longer claims Cowork support — it points at the `roadmap/cowork-codex` branch instead.

### Smaller items

- Hero subhead reframed to lead with human behavior instead of infrastructure terms.
- `README.md` Step 3 reframed from "DO NOT SKIP THIS" to opt-in emergent seeding as the default.
- `LIMITATIONS.md` no longer references a command that doesn't exist.
- `docs/update-protocol.md` channel-switch example bumped from v0.4.0 to v0.7.0.

**Upgrade:** pure documentation + presentation release — no code paths changed, existing installs see zero drift.
