### Highlights

- **Jobs that run** — `claude` and `basic-memory` resolve under launchd via the manifest with a PATH sweep fallback; `flock` (util-linux, absent on macOS) no longer fails every job; doctor reports job health with a named cause instead of "the file exists".
- **`/thinkos-refresh` is the one refresh** — absorbs `/thinkos-reindex`, `/validate-os`, `/thinkos-stale` and `/index-projects`. Reindex runs after writes, Current Focus waits for fresh Tasks, and closing done items happens in the same pass that adds new ones.
- **Tasks as data** — Tasks-plugin syntax (priority, due, done, tags) so Obsidian Bases and the Tasks plugin can query them.
- **`thinkos-deck` skill** — builds or improves Google Slides decks from Meetings, Work Log, Decisions and Learnings; applies the tiered privacy rules; refuses to mutate without a backup.
- **`/thinkos-loose-ends`**, **`/thinkos-figma-triage`**, **`/thinkos-timesheet`** and a **Composio bridge** for sources the first-party MCPs don't cover.
- **Privacy classification, now tiered** — the flat keyword list redacted small talk and missed a serious medical discussion; terms are now judged by domain.
- **Removed** — `/thinkos-log`, `/thinkos-save`, `/thinkos-decide` (use `/thinkos-capture --mode …`), and the `linear` and `jira` connectors, which had never produced a ledger entry.

### Upgrade

`/thinkos-update --pull`. The update repairs the launchd jobs on existing installs; run `/thinkos-doctor` afterwards and expect the job-health checks to go green.
