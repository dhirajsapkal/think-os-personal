### Highlights

- **`scripts/session-activity.py`** — timestamp-accurate per-project, per-day activity from Claude Code session logs. Deliberately conservative: an attribution signal, not a total.
- **`scripts/harvest-timesheet.py`** — give it a plan, it issues the minimum create/update/delete to make a Harvest week match. Idempotent; never touches entries already submitted or approved. Submitting stays manual, because it is an attestation.
- **`/thinkos-timesheet`** — gathers the week's inputs, proposes a split to react to, shows the diff, applies only on explicit confirmation.
- **The capture bug** — `thinkos-session-capture.sh` selected session files by modification time and counted every edit a file had ever contained, so any touch replayed the whole history as "today's work". Fixed: each entry is filtered by its own timestamp, and the capture marker advances only after a successful write.

### Upgrade

`/thinkos-update --pull` picks it up. Work-log entries written by the previous capture are not reliable; `session-activity.py` reads the raw session files and is correct for any period they still cover.
