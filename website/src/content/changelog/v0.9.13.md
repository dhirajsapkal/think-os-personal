### Highlights

- **`scripts/lib/check-hook-paths.py`**, wired into doctor — scans every hook and agent for vault-shaped paths and reports `hooks:dead-paths` (fail: the path does not exist) and `hooks:foreign-vault` (warn: it exists but resolves outside the active vault).
- **Paths with spaces** — the first version of the checker stopped at whitespace and passed a path it had been pointed straight at. Vault paths routinely contain spaces (`01 Now`), which is precisely the class it was built to catch.
- **Empty results now warn** — a process substitution whose command dies feeds the loop nothing, which looked identical to a clean pass.

### Upgrade

`/thinkos-update --pull`, then `/thinkos-doctor`. Verify doctor by counting checks, not by exit status.
