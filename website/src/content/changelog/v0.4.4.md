### What changed

- `/thinkos-save` Step 0 now uses topic-overlap comparison instead of timestamp proximity. Only prompts on actual semantic overlap; proceeds silently otherwise.
- Step 3 ledger event template requires a `topic` field in `detail` so future invocations can detect overlap without re-reading vault content.
- New core operating rule in the priority preamble: "Multi-instance Claude is normal. For any dedup check, compare semantic overlap, not timestamp proximity." Applies platform-wide — gets it right at the layer below every capture command.
