### Highlights

- **A new visual world, dark by default** — the site is now a terminal session viewed at night: a dark room, file-panes that glow as lit phosphor artifacts, a green accent. The old warm-paper-with-navy look survives as "The Printout," the second theme behind the toggle. The first screen reads instantly as a different site
- **The type system is retired and replaced** — Newsreader, Hanken Grotesk, and IBM Plex Mono are gone; **Bricolage Grotesque** now carries display and body, **JetBrains Mono** the machine voice. Both self-hosted via fontsource, no CDN
- **Scroll is the narrative engine** — the homepage plays like a session unfolding: commands type themselves as each scene enters the viewport, diffs write in line-by-line, deletions strike through, and a live clock in the top bar advances across one workday (`08:40 → 14:02 → … → Sun 20:14`) as you move down the page
- **Two things you can actually click** — command chips (`/thinkos-morning`, `/thinkos-decide`, `/weekly-review`) swap which vignette plays; a mock terminal types and "runs" a preset command you pick
- **Window chrome on every page** — a fixed top `SessionBar` styles the whole site as one maximized terminal window, replacing the old header
- **Every page came along** — the guide, commands, docs, changelog, and 404 are all restyled into the new world; no page left looking like v1
- **Website-only release** — no scripts, templates, instructions, or playbooks changed

### What changed

v0.9.5 rebuilt the homepage around a single device — a two-pane Pair showing what you typed and the file that changed — and the *content* moved on. But the design didn't: same typography, same centered-prose column, same light-paper palette. A client's read was blunt — it still looked like version 1. This release makes the 2.0 a visible fact.

The whole stylesheet was rewritten around a dark-first "Live Session" world. The default theme is a night-terminal room where panes are lit bodies with a faint phosphor bloom, a fixed dotted grid gives the room its texture, and selection and focus rings glow green. The light theme is recast as "The Printout" — the same artifacts run to a warm sheet of paper — and stays a fully coherent second world behind the existing toggle, AA-contrast verified in both. The type changed with it: Newsreader / Hanken Grotesk / IBM Plex Mono are retired in favor of self-hosted Bricolage Grotesque (display and body) and JetBrains Mono (the machine voice).

The layout grammar changed too. The homepage is no longer a centered prose column with a kicker-and-heading rhythm; it's a sequence of full-bleed scenes, each timestamped across a single workday, and scroll is what plays them. Commands type themselves as each scene enters the viewport, diffs write in line-by-line and deletions strike left-to-right on reveal, and a live clock in the top `SessionBar` advances as you scroll. Two moments are genuinely interactive: a `CommandStage` whose command chips swap which vignette plays (the three former "day with it" beats), and a `TryTerminal` that types and runs whichever preset command you choose.

The good bones from v0.9.5 — the `Pair`, the terminal / file / diff panes, the typewriter — were restaged and restyled inside the new world rather than rebuilt. Every page came along: the guide and docs, the commands filter and table, the changelog index, the 404 `cat`-miss, and the install card all wear the dark-first palette and the new type.

Everything degrades. `prefers-reduced-motion` collapses every device to its final static, fully-visible state — nothing hides behind animation. With no JavaScript the page is fully readable: reveals only *add* motion, the interactive chips and presets fall back to static stacked panels, and the clock stays honest. Focus-visible rings, the skip link, the second theme, and the Think Company attribution are all intact, and the interactivity is vanilla JS plus `IntersectionObserver` and CSS — no new heavy dependencies. Every behavioral claim still traces to a shipped playbook: the chips are real commands and behave as their markdown describes. The version stamp, changelog collection, RSS feed, 404, both `netlify.toml` files, and the standalone-deploy build are unchanged and green.

### Upgrade

Nothing to do — this is a website-only release. `/thinkos-update --pull` does not touch the site; pull the repo to see the rebuilt pages. Standalone Netlify deploys of `website/` build unchanged via `npm run build` (the `prebuild` step still snapshots `VERSION`).
