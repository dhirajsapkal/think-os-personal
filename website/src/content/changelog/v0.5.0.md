### Highlights

- Vault fills in from natural conversation instead of a 30-minute setup step
- Agent flags stale context mid-flow, not just at weekly review
- Shared-mode hides sensitive notes during screen sharing
- One canonical capture command — three soft aliases that keep working

### What changed

**Emergent seeding.** The previous Phase 2 step was framed as required; people who didn't finish it got an empty-feeling vault and an under-personalized agent. The contract is now inverted: start empty, let the agent surface what it learns from your real conversations, save on explicit confirmation. Per-file draft state lives in `~/.thinkos/emergent-state.json`, capped at three deferrals per file before going silent. `/thinkos-continue` is still there for power users with rich connector data — it just isn't blocking anymore.

**Agent-initiated drift detection.** The agent now flags four contradiction types mid-flow with a bounded one-line nudge: Identity vs. recent Work Log, stale `covers_week`, an unknown person mentioned by name, a project not in the index. Auto-muted after `/weekly-review` until the next Sunday, silent in shared-mode, max one nudge per session, max one re-surface per topic per week.

**Capture surface consolidated.** Four slash commands had become four ways to do the same thing. `/thinkos-capture` is now the canonical multi-type handler with type inference: verb phrasing like "from now on" routes to decision, "noticed that" to learning, first-person past-tense to log, multi-paragraph or empty input to session-recap. `/thinkos-log`, `/thinkos-decide`, `/thinkos-save` reshape as ~14-line soft aliases — same behavior, one fewer command to remember.

**Privacy tiers + shared-mode.** New optional `tier: standard | sensitive` frontmatter field. When shared-mode is active (flag file or `THINKOS_SHARED=1` env), the agent post-filters search results to drop sensitive notes and refuses reads with a redaction message. Activate before a screen share, deactivate after.

**Cost-of-context skip rule.** When CWD is a registered project AND the question is project-local factual (no first-person pronouns, no identity/focus/decisions keywords), the agent now skips the two mandatory MCP reads. Conservative bias — false negatives are recoverable, false positives are not.
