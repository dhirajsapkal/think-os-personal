### What changed

- `scripts/thinkos-update.sh` now recomputes `shipped_sha` and `current_sha` for every managed file at the end of each run. Previously these were only updated during migration, so subsequent `--skip-pull` runs accumulated false-positive drift over time.
- `/thinkos-update` now offers four chip options when drift is detected (was three): "Back up and replace" (safe default), "Just replace, no backup" (new — for system-caused drift), "Keep mine", "Show diff first". The playbook explains when no-backup is the right call so you can choose without guilt.
