### Highlights

- Cowork and Codex adapters moved to a long-lived `roadmap/cowork-codex` branch
- Every install script, setup flag, and doc page now reflects what's actually wired up
- Zero new commands, zero new behavior — just a smaller, more honest surface

### What changed

The `adapters/claude-cowork/` and `adapters/codex/` trees came out of `main`. They were carrying real cost — grep noise across the repo, six scripts with dead branches, `--products` flags that listed surfaces the installer couldn't reach, and a website front page that promised Cowork support. None of it was active code; all of it was load-bearing on user trust.

Everything is preserved verbatim on `roadmap/cowork-codex`. One `git cherry-pick` away from coming back when either Cowork's plugin format stabilizes (it doesn't yet) or Codex grows install ergonomics worth automating.

What you get on `main` now: a branch where every shipped surface actually works, scripts with no dead arms, and a website that matches the tree. The README, AGENTS.md, LIMITATIONS.md, and the website FAQ all gained a one-line pointer to the roadmap branch so the cut isn't invisible.

### Smaller items

- `setup/manifest.yaml`: `codex-block` managed-files entry removed.
- Six scripts cleaned — `usage()` blocks, `--products` help, `all`-expansion, manifest writer/reader, install/uninstall functions.
- Dead plumbing pruned in `thinkos-uninstall.sh` — variables threading empty values through three call sites are now fully gone.
- `docs/update-protocol.md`: Cowork reapply path and Codex managed-file example removed.

**Upgrade:** `/thinkos-update` from any session.
