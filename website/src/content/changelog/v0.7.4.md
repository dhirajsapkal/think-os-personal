### Highlights

- **Eight placeholder MCP URLs in the plugin catalog replaced with verified endpoints** — Gmail, Drive, Calendar, Atlassian, HubSpot, QuickBooks, PubMed, Zoom
- **Google Calendar added to all four presets** (it was in the catalog but no bundle included it — `/thinkos-morning`'s calendar pull silently got nothing)
- **Installer no longer silently skips installs on machines signed into claude.ai** — new `bridge_match` field and an explicit "provided by the claude.ai bridge" status

### What happened

Three failures stacked on the same path. The catalog had `TODO: verify` URLs that would have failed on first connection — except nobody hit them, because the installer's "already registered" guard fell back to a loose substring grep against `claude mcp list`. On any machine signed into claude.ai, searching for `gmail` matched the bridge entry's URL substring `gmailmcp`, the function returned success, and the installer logged `SKIPPED: 'gmail' already registered`. The manifest claimed gmail/slack/notion/granola were installed; `~/.claude.json` had none of them.

And separately: Google Calendar simply wasn't in any preset. Anyone who picked a bundle expecting "Claude can see my calendar" got nothing.

### What changed

The installer's contract is tighter now: a local install attempt either succeeds with a working URL, gets cleanly deferred to the bridge (reported in its own summary section, pointing at the `mcp__claude_ai_<Service>__*` namespace), or fails loudly. Catalog entries gained an optional `bridge_match` field naming the exact `claude.ai <Display Name>` row the bridge provides. `claude mcp list` output is now cached per run instead of probed three times per item.

### Smaller items

- `google-drive` added to the pm/eng/design presets.
- `setup/manifest.yaml` bundle descriptions updated so the chip-picker shows what you'll actually get.
- Remaining unverified catalog entries stay marked — they're excluded from presets until confirmed.

**Upgrade:** `/thinkos-update` from any session, then re-run the bundle install if your earlier one reported suspicious `SKIPPED` lines.
