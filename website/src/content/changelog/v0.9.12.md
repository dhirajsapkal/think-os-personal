### Highlights

- **`scripts/thinkos-checkpoint.sh`** — a Stop hook that extracts decisions, learnings, open questions, artifacts and commitments from the transcript slice since the last checkpoint and stages them to `90 System/Session Checkpoints/`. Incremental, and gated so a trivial session costs nothing.
- **`/thinkos-promote`** — walks unreviewed checkpoints, proposes a target per item, files only what you approve. Declining marks an item reviewed so it never comes back.
- **`scripts/lib/model-routing.sh`** — one table mapping task to model, read by every scheduled job, overridable per task or globally.
- **The routing lesson** — checkpoint extraction was first routed to Haiku and that was wrong: a transcript describes what was proposed in the same confident past tense as what was done, and separating them is judgment. The doctrine gained the test that catches it: does the input state the answer unambiguously?
- SessionStart now reports unreviewed checkpoints so staged work does not pile up unread.
