### Highlights

- Working anchors for each release — `/changelog/#v0-7-0` lands on the right entry
- RSS URLs normalized — no more trailing slash after the fragment
- A quiet `:target` flash so the eye finds the entry you linked to

### What changed

Links like `/changelog/#v0-7-0` previously resolved nowhere because the rendered entries had no `id` attribute. Each entry now carries one, `scroll-mt-24` keeps the target from landing under the header, and the version stamp in each entry is a self-link — click it to copy the per-release URL.

On the feed side, `@astrojs/rss` was emitting URLs like `https://thinkos.dev/changelog/#v0-7-0/` — trailing slash *after* the fragment — which some readers tolerated and some treated as broken. The feed now constructs URLs explicitly and appends the fragment last, so output is clean.

The new anchor flash respects `prefers-reduced-motion` — no animation if you have it set.

**Upgrade:** website-only release; nothing to do.
