# Think OS Agent Guide For Claude

This repository is the export package for Think OS. When helping with setup, read `AGENTS.md` first, then follow `docs/agent-setup-playbook.md`.

Prefer the scripts:

- `scripts/thinkos-doctor.sh --json --products <list>` to inspect setup state.
- `scripts/thinkos-setup.sh --products <list> --install-basic-memory --yes` to perform safe setup steps.

Do not manually read the user's live vault during installation unless they explicitly ask you to inspect their notes.
