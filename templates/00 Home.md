# Think OS Home

Dashboard and portal for your personal context OS. Open this first when you want to orient, jump into a specific part of the knowledgebase, or see what the agent should know.

## Now

- [[01 Now/Current Focus|Current Focus]] — priorities and active threads for this week
- [[01 Now/Tasks|Tasks]] — connector-synced inbox plus manually added tasks
- [[01 Now/Work Log|Work Log]] — recent sessions, outcomes, and continuity notes

## Projects

- [[02 Projects/Project Index|Project Index]] — active, paused, monitoring, and recently completed projects
- [[02 Projects/_Project Template|Project Template]] — starting point for a new project note

## People

- [[03 People/People|People]] — collaborators, stakeholders, preferences, and relationship context

## Knowledge

- [[04 Knowledge/Decisions|Decisions]] — standing decisions the agent should not relitigate
- [[04 Knowledge/Learnings|Learnings]] — reusable patterns, lessons, and tagged insights

## Profile

- [[05 Profile/Identity|Identity]] — who you are, how you work, and hard guardrails
- [[05 Profile/Business Brain|Business Brain]] — strategy, principles, and business context
- [[05 Profile/Voice Profile|Voice Profile]] — writing patterns and rewrite examples

## System

- [[90 System/OS Instructions|OS Instructions]] — how agents should load, use, and update Think OS
- [[90 System/Connectors|Connectors]] — MCP servers, app connectors, auth state, and usage rules
- [[99 Archive/Archive Index|Archive]] — rotated logs, dormant notes, and older context

## Vault Map

| Area | What goes here | When to open it |
|---|---|---|
| `01 Now/` | Current focus, task inbox, work log | Daily or weekly review |
| `02 Projects/` | Project index and one note per project | Starting or resuming project work |
| `03 People/` | Lightweight personal CRM | Before meetings, drafts, or stakeholder questions |
| `04 Knowledge/` | Decisions and reusable learnings | Before recommending an approach |
| `05 Profile/` | Identity, voice, business context | Annual review, voice tuning, onboarding |
| `90 System/` | Agent instructions and connector map | Setup, debugging, changing rules |
| `99 Archive/` | Rotated logs and dormant project notes | Only when looking backward |

## Maintenance

- Daily: check [[01 Now/Current Focus|Current Focus]] and [[01 Now/Tasks|Tasks]]
- Weekly: roll [[01 Now/Current Focus|Current Focus]] forward and scan [[02 Projects/Project Index|Project Index]]
- Quarterly: archive [[01 Now/Work Log|Work Log]], prune [[90 System/Connectors|Connectors]], and promote stable [[05 Profile/Voice Profile|Voice Profile]] patterns
